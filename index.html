Stellar Clustering: Evaluating Clustering Methods for Reconstructing Hertzsprung–Russell Diagrams

Independent research project as part of the Women in Mathematics Directed Research Program (S26) at the University of Waterloo, supervised by mentors Téa Fazio and Gaia Noseworthy.

Overview: This project uses a quality filtered sample of Gaia Data Release 3 (DR3) stellar data to construct a Hertzsprung-Russel (HR) diagram, and performs unsupervised clustering using K-Means, DBSCAN (Density-Based Spatial Clustering of Applications with Noise), and GMM (Gaussian Mixture Modelling). The goal is to investigate whether these unsupervised clustering methods can recover meaningful stellar population groupings within the HR diagram, and determine which method gives the most astronomically informative results.

Jupyter Notebook Python - Matplotlib Python - pandas Python - numpy Python - SciKit-Learn

Chaos Theory and Analysis on the Double Pendulum System

F25 AMATH 251 research final project on modeling and analyzing the double pendulum using numerical methods.

Abstract: The double pendulum is a classic example of a nonlinear, deterministic system that exhibits both pre- dictable and chaotic behaviour depending on its initial conditions. In this report, we aim to investigate how a double pendulum evolves with time, and analyze its behaviour numerically using the Runge-Kutta 4-th Order numerical method.
